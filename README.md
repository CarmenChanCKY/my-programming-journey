# my-programming-journey

A programming blog developed by Nuxt 3, Vue 3 and Typescript

## Tech Stack

- [Nuxt 3](https://nuxt.com/) - Vue Framework
- [Vue 3](https://vuejs.org/) - Frontend Framework
- [TypeScript](https://www.typescriptlang.org/) - Type Safety
- [Pinia](https://pinia.vuejs.org/) - State Management
- [Vuetify](https://vuetifyjs.com/) - UI Components
- [Prism](https://prismjs.com/) - Code Syntax Highlighting
- [SCSS](https://sass-lang.com/) - Styling

## Requirements

- Node.js v20.11.1 or later
- npm/yarn/pnpm package manager

## Setup

Make sure to install dependencies:

```bash
# npm
npm install
```

Configure environment variables:

- Set `NUXT_PUBLIC_BACKEND_URL` in `.env.local` and `.env.production`


## Development Server

Start the development server on `http://localhost:3000`:

```bash
# npm
npm run dev
```

## Production

Build the application for production:

```bash
# npm
npm run build
```

Locally preview production build:

```bash
# npm
npm run preview
```
